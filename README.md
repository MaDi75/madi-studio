# MaDi Studio

A small arithmetic practice app for the browser. Short rounds, no accounts, no build step.

## Features

- Addition, subtraction, multiplication, and exact division
- Practice, match, and quiz modes
- Russian and English
- Five difficulty levels, 6–12 questions per round
- Optional penalty for wrong answers
- Local history and day streak
- Optional sound
- Installable as a PWA

## Run

```bash
python -m http.server 8765
```

Open `index.html`.

# MaDi Studio

Небольшое приложение для практики арифметики в браузере. Короткие раунды, без аккаунтов и без сборки.

## Возможности

- Сложение, вычитание, умножение и деление нацело
- Режимы: практика, соединение ответов, викторина
- Русский и английский
- Пять уровней сложности, 6–12 вопросов в раунде
- Необязательный штраф за ошибку
- Локальная история и серия дней
- Опциональный звук
- Можно поставить как PWA

## Запуск

```bash
python -m http.server 8765
```

Открой `index.html`.
