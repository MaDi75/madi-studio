# Contributing

MaDi Studio is a small browser project built with HTML, CSS, and JavaScript. There is no build step.

## Getting started

1. Open an issue or pick an existing one.
2. Fork the repository and create a branch with a clear name.
3. Check your changes with `python -m http.server` in the project root.
4. Open a pull request with a short description. Add a screenshot if the interface changed.

## Useful contributions

- Bugs in question generation, timers, sound, or PWA
- Accessibility and keyboard flow
- Extra translations on top of RU/EN
- Calmer sound and visual rhythm

## Guidelines

- Keep the one-page flow: setup → countdown → round → result.
- Do not send user data to a server. Progress stays in `localStorage`.
- Do not add large third-party code without a license.
- Use the issue and pull request templates in `.github`.

Thank you for helping.

# Как помочь проекту

MaDi Studio — небольшой браузерный проект на HTML, CSS и JavaScript. Сборка не нужна.

## С чего начать

1. Открой issue или возьми уже существующий.
2. Сделай форк и ветку с понятным именем.
3. Проверь изменения через `python -m http.server` в корне репозитория.
4. Пришли pull request с коротким описанием и, если меняется интерфейс, скриншотом.

## Что особенно полезно

- Баги в генерации примеров, таймерах, звуке и PWA
- Улучшения доступности и клавиатурного ввода
- Переводы поверх RU/EN
- Более спокойный звук и визуальный ритм

## Правила

- Не ломай одностраничный поток: настройка → обратный отсчёт → раунд → результат.
- Не отправляй данные пользователя на сервер. Прогресс только в `localStorage`.
- Не добавляй большие сторонние куски кода без лицензии.
- Для issue и PR используй шаблоны в `.github`.

Спасибо за помощь.
