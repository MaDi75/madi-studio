# Code of Conduct

This project follows the [Contributor Covenant](https://www.contributor-covenant.org/version/2/0/code_of_conduct.html), version 2.0.

## Pledge

We want a calm, welcoming space for anyone who wants to practice maths or improve this app.

## Standards

Helpful behaviour includes kindness, clear feedback, and focusing on the work.

Unwelcome behaviour includes harassment, insults, publishing private information, and anything that makes the project unsafe.

## Enforcement

Project maintainers may edit or remove comments, issues, and pull requests that break this code of conduct.

To report a problem, open a private report through GitHub or contact the repository owner.

# Кодекс поведения

Этот проект следует [Contributor Covenant](https://www.contributor-covenant.org/version/2/0/code_of_conduct.html) версии 2.0.

## Обещание

Здесь должно быть спокойно и доброжелательно всем, кто хочет потренировать арифметику или улучшить приложение.

## Нормы

Полезное поведение: доброжелательность, понятная обратная связь и внимание к работе.

Недопустимы оскорбления, травля, публикация чужих личных данных и всё, что делает проект небезопасным.

## Применение

Сопровождающие могут править или удалять комментарии, issue и pull request, если они нарушают этот кодекс.

О проблеме можно сообщить приватным отчётом на GitHub или владельцу репозитория.
